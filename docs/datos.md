# Acuerdo de integración pendiente

Validar con el equipo 1 antes de definir tipos definitivos:

- Claves de estado y municipio como cadenas para conservar ceros iniciales; documentar catálogo y versión.
- Año electoral, fuente, denominador y unidad de cada indicador.
- Diferenciar valores faltantes de cero; documentar cobertura temporal y territorial.
- Identificador, nombre, descripción y métricas de cada cluster, definidos por el análisis.
- Geometrías, licencia, fuente y nivel de detalle para el mapa.
- Formato de entrega, versión del esquema y fecha de actualización.

Los datos simulados deben etiquetarse visiblemente y mantenerse separados de los resultados reales. No se incluyen datos simulados en esta base.
